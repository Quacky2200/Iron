# emoji (Emoji parade)

A self-running stage show. A spinner wheel picks one of 50 performers (48 Noto Emoji plus two drawn in code, whose
eyes follow the mouse). A red curtain opens, the emoji enters in one of several ways, strikes a pose in a
spotlight while its name appears, the crowd reacts (applause, cheers, boos with thrown tomatoes, gasps, laughs),
and it leaves. Many emoji have a show of their own (storms, disco lights, a haunted night, a rocket launch).
It is the largest example (about 4700 lines in 15 files) and shows how to build a whole animated production with
2D shapes, world-space React panels, particles and synthesised sound.

Engine features used: orthographic `Camera`, `WorldPanel` (React UI on a plane, with `tint`, `resolution`,
`interactive: false`), `createRoot(panel)`, `LineRenderer2D` and `Shapes`, `Image` with SVG assets, `audio.load` /
`Sound.play` / `Playback.stop` / `onEnded`, `Screen.aspect`, `input.mousePosition`, `addStyleSheet`, `setTimeout`,
`register`, a screen-space React `Hud`.

## Build and run

```bash
cd tools && cargo run -q -p platypus_build -- build ../examples/emoji
```

Then, from the repo root:

```bash
cargo run -p platypus_app -- examples/emoji
```

Package with `platypus-build package ../examples/emoji`. A screenshot run is
`platypus-app examples/emoji --screenshot out.png --frames N` (the show is random; a screenshot catches a random
moment). It is the safest check, since the interactive window has crashed some GPUs.

## How it works

**Setup.** `register({ Parade, Mote })` spawns the director. `Parade.onAwake` makes an orthographic camera
(`orthographicSize: 5`), builds the stage and curtain, preloads all sounds, creates the actor (a `WorldPanel` on a
child object, 480 px for 4.7 world units) and renders the Hud with `createRoot().render(<Hud />)`.

**State from code to React.** The director writes small `Store<T>` objects; components call `store.use()` which
re-renders on change. No props are passed through the engine:

```ts
export const shown = new Store<Shown>({ code: "1f600", look: null, mirror: false, big: false });
export const caption = new Store<string | null>(null);
```

**Phases.** `onUpdate` is a `switch` on a string `phase`: `wheel` (the spinner), `enter`, `pose`, `exit`, then
`close` (or `miss` when an entrance such as `rollcrash` crashes past). Each uses `this.t` as the act's clock.

**Acts are pure functions.** An `Act` has a duration, `at(t)` returning a `Move` (position along the way in,
lift, squash/stretch, rotation, tint, curtain opening...) and optional `cues`, `[time, fn]` pairs that fire sounds
and effects once. The director applies the `Move`; an entrance looks like this:

```ts
const walk: Act = {
  name: "walk",
  dur: 7,
  weight: 10,
  at(t) {
    const m = still();
    const u = clamp01(t / 7);
```

Choice is weighted (`weighted(ENTRANCES)`) unless `SPECIAL` names one. `rewind(act)` plays an act backwards.

**The wheel.** Eight random performers go on a React `Wheel`; the target angle is
`360 * 5 - winner * 45 + jitter`, eased with `1 - (1 - u) ** 3.4`, and a "peg" tick plays every 45 degrees.

**Applying a move.** `apply` sets the actor's `position`, `localScale` and `localEulerAngles`, adds a shiver from
`jolt`, dims it by distance from the spotlight and sets `panel.tint` only when the string key changes. The shadow
scales with height. `m.swap` swaps the shown Noto file (a wink).

**Cues and crowd.** `runCues` runs every cue whose time has passed. `react()` plays applause, cheers (with
confetti `burst`), boos (with `effects.throwTomatoes`), gasps (a `jolt`), and so on, at `reactAt` seconds into
the pose.

**Particles and props.** `Fx` is a pool of 450 `LineRenderer2D` capsules reused round-robin; `Sprites` is a pool
of 48 emoji `WorldPanel`s. Both avoid creating objects per frame.

**Eyes.** For the two code-drawn performers, `watch` aims pupils at `input.mousePosition` converted to world
units (or wanders after 2.5 s idle) and blinks on a random timer.

## Controls

None: the show runs by itself. The two "eyes" performers follow the mouse.

## Things to try

- Add an emoji: copy the SVG into `assets/emoji/`, add a row to `ROWS` in `cast.ts`, a line in `specials.ts`.
- Write a new entrance in `entrances.ts` as an `Act` and add it to the exported list.
- Add a button to the Hud that skips to the next performer or lets the player pick.
- Use the `Store` pattern to drive any React overlay from game code.
- Reuse `Fx` / `Sprites` pools for hit effects in another game.

## Gotchas

- Code style is plain: explicit types, `for` loops, `const self = this` before closures, `!` after indexing.
  Types such as `Phase = string` are used instead of unions and the interfaces are small.
- The source keeps motion as pure data (functions of time) so it is easy to test and rewind; state is on the
  director only.
- `view.half` is recalculated from `Screen.aspect` every frame; the curtain is made for one width and stretched.
- Panel size is fixed per panel: the rocket gets a bigger one (`BIG`) because the picture is clipped to its panel.
- The header comment says "thirteen" entrances and "eighteen" exits; the lists in code have 13 and 11 `name:` entries,
  so the comment may be out of date.
- The `liftoff.mp3` clip is cut at 6 s with `setTimeout(() => playback.stop(...))`.
